# Nene's Divaloper Statistics Dashboard

A customised GitHub developer statistics dashboard built using existing resources, code customisation and real GitHub data.

## About the Project

Nene's Divaloper Statistics Dashboard is a personal project created to explore how GitHub activity and developer statistics can be collected, processed and presented through a customised web dashboard.

The idea started when I watched Magdeline Huang's YouTube video  for inspiration on enhancing a GitHub profile. This introduced me to different ways of displaying developer statistics and motivated me to explore the idea further. What started as an interest in improving my GitHub profile grew into a project where I worked on customising and improving a dashboard of my own.

I used existing resources and code as a starting point - including GitHub Readme Stats. I adapted, customised, debugged and improved the code to suit my goals. My focus was on making the dashboard more personal, informative and useful.

## What I Learned

This project gave me the chance to work on a website entirely through GitHub, without using an IDE. I learned how to publish my website using GitHub Pages and about fine-grained and classic personal access tokens and their different permissions. I also spent time fixing and customising existing code to get the dashboard working the way I wanted - especially getting my contribution graph to match the one on my GitHub profile.

## Project Summary

Nene's Divaloper Statistics Dashboard is a web-based project that brings my GitHub activity and developer statistics together in one place. It provides a personalised summary of my GitHub profile, making it easier to view statistics such as contributions, commits, repositories and programming language usage, including information that is not already displayed or calculated for me on my profile.
